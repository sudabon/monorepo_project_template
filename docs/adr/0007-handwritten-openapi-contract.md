# 0007: 契約は手書きし、実装からは生成しない

- 状態: 採用
- 日付: 2026-09-06

## 判断

公開契約は `api/openapi.yaml` を人が書く。Go のコメントやアノテーションから OpenAPI を生成しない。仕様を先に固定し、Go と TypeScript の実装はそのファイルから生成する。

生成ツール自体の選定は [ADR 0002](0002-openapi-contract-tools.md)。

## 理由

実装の都合が契約に漏れると、クライアント側の変更が「サーバを直さないと始まらない」構造になる。手書きにすると、契約変更はレビュー対象の YAML になり、両言語が同じ入力から追従する。

## 代替案

| 案 | 結果 |
| --- | --- |
| swaggo 等で Go から OpenAPI を生成する | 契約が実装に引きずられる。却下 |
| TypeSpec などの中間 DSL から OpenAPI を生成する | 依存とビルド段数が 1 つ増える。OpenAPI を直接書けば足りる。却下 |

参考: Phase 1 `design.md` D1、[ADR 0002](0002-openapi-contract-tools.md)。
