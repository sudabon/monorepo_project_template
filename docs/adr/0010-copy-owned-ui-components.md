# 0010: UI 部品はコピー型で持つ

- 状態: 採用
- 日付: 2026-09-06

## 判断

ボタン・入力・モーダル・テーブル・トーストは `apps/web/src/components/ui/` のソースとして持つ。UI コンポーネントライブラリを依存に追加しない。shadcn/ui の「生成したコードを自分のリポジトリで所有する」方式に倣う。ダークモードは実装しない。

## 理由

パッケージとして UI キットに乗ると、メジャー更新のたびに全画面の見た目とアクセシビリティが同時に壊れ得る。コピー型は初期の記述量と引き換えに、更新範囲を自分で制御できる。テンプレートの画面数は少なく、その対価は払える。

## 代替案

| 案 | 結果 |
| --- | --- |
| MUI / Chakra 等を依存に追加する | デザインと a11y の方針がライブラリに固定される。メジャー更新の影響面が大きい。却下 |
| shadcn/ui の CLI を案件のビルドに組み込む | テンプレート初期値としては、既にコピーした部品があれば足りる。CLI を必須にしない |
| ヘッドレスライブラリ（Radix 等）だけを足す | モーダルのフォーカス管理は楽になるが、依存とメジャー更新は残る。必要になった案件で足す |

キーボード操作とフォーカス管理は自前になる。不足は `TODO(template):` として部品に残している。
