## E2Eテスト実装タスク(必須)

本 change は E2E 不要のため test-plan.md を持たない(テンプレート方針として Playwright のスモークは
Phase 5 の 1 本のみとするため)。したがって `@phase4-react-spa-skeleton` タグを持つ E2E テストは
実装しない。骨格の振る舞いは Vitest + Testing Library のコンポーネントテストで検証し、タスク 2〜7 で
指定している。ログイン画面の表示と認証ガードの遷移は Phase 5 のスモークの起点として間接的に通る。

未解決の判断は design.md - Open Questions に記載している(「API 停止時に白画面にならない」を
E2E で押さえるべきか)。スモーク 1 本の制約を緩める判断が出た場合は、本 change に test-plan.md を
追加し、対応する実装タスクをここに追記する。
