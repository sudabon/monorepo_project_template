## MODIFIED Requirements

### Requirement: 構造化ログとリクエスト ID の伝播

サービスはログを構造化形式で出力しなければならない (MUST)。各リクエストにはリクエスト ID を割り当てなければならない (MUST)。クライアントがリクエスト ID を送ってきた場合はそれを引き継ぎ、ない場合は新たに生成しなければならない (MUST)。同一リクエストの処理中に出力されるログには、同じリクエスト ID が含まれなければならない (MUST)。サービスが下流のサービスを呼び出す場合、そのリクエストにも同じリクエスト ID を引き継がせなければならない (MUST)。

#### Scenario: リクエスト ID の生成

- **WHEN** リクエスト ID を含まないリクエストを送る
- **THEN** サービスがリクエスト ID を生成し、応答と、そのリクエストに関するすべてのログに同じ ID が含まれる

#### Scenario: リクエスト ID の引き継ぎ

- **WHEN** リクエスト ID を含むリクエストを送る
- **THEN** そのリクエストに関するログと応答に、送った ID と同じ値が含まれる

#### Scenario: エラー時の追跡

- **WHEN** サーバ内部エラーが発生するリクエストを送る
- **THEN** エラーログにリクエスト ID が含まれ、応答からも同じ ID を得られる

#### Scenario: 下流サービスへの伝播

- **WHEN** リクエストを受けたサービスが、その処理の中で下流のサービスを呼び出す
- **THEN** 下流への要求に、受け取った、または生成したものと同じリクエスト ID が含まれる
