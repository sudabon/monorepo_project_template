## E2Eテスト実装タスク(必須)

本 change は E2E 不要のため test-plan.md を持たない(ログイン画面が存在せず、Cookie 属性・CSRF・
401・ヘッダ詐称はいずれも HTTP レベルで完結して検証できるため。Playwright のスモークはテンプレート
方針として Phase 5 の 1 本のみとする)。したがって `@phase3-go-bff-auth` タグを持つ E2E テストは
実装しない。各シナリオの検証は Go の統合テストで行い、タスク 2〜5 で指定している。
